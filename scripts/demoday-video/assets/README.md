# Branding assets

Place the validated transparent KERNO monogram here before running the capture export:

```text
scripts/demoday-video/assets/kerno-logo.png
```

Expected asset:

- square PNG;
- transparent background;
- validated green, white and orange monogram;
- recommended size: at least 1000 × 1000 pixels.

This file is used in Clipchamp for the opening title, the supplier-to-store transition and the final screen. It is not used inside the local KERNO interface and does not modify the application branding.
